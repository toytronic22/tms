# TeachMeSkills: Automation QA Engineer (C#)

Учебный репозиторий курса TeachMeSkills «Automation QA Engineer (C#)», май — октябрь 2026.

## Дипломный проект: Final Surge

[FinalSurge](FinalSurge/) — автотесты сервиса тренировок [Final Surge](https://log.finalsurge.com/): 12 UI-тестов, 15 API-тестов и 10 BDD-сценариев.

C# / .NET 10, NUnit 4, Selenium WebDriver (Page Object, Page Factory), RestSharp, Reqnroll, Allure, log4net. Прогон — в Jenkins с Selenium Grid в Docker, итог сборки приходит в Telegram.

Как устроен проект и как его запустить — в [README диплома](FinalSurge/README.md).
