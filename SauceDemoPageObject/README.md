# SauceDemo — автотесты на Page Object Pattern

Учебный проект по автоматизации UI для https://www.saucedemo.com

## Структура

```
SauceDemoPageObject/
├── SauceDemo.Core/          библиотека с Page Object классами
│   └── Pages/
│       ├── BasePage.cs                  общий родитель: драйвер, открытие сайта, ожидания
│       ├── LoginPage.cs                 страница логина
│       ├── ProductsPage.cs              страница товаров
│       ├── HeaderSection.cs             шапка: бургер-меню, logout, корзина
│       ├── CartPage.cs                  корзина
│       ├── CheckoutInformationPage.cs   оформление, шаг 1 (данные покупателя)
│       ├── CheckoutOverviewPage.cs      оформление, шаг 2 (суммы)
│       └── CheckoutCompletePage.cs      успешное оформление
└── SauceDemo.Tests/         тесты NUnit
    ├── BaseTest.cs
    ├── LoginTests.cs
    ├── CartTests.cs
    └── CheckoutTests.cs
```

Тестовые данные: `standard_user` / `secret_sauce` (указаны на главной странице приложения).

## Запуск

```
dotnet test
```

Браузер — Chrome, запускается в гостевом режиме (`--guest`), окно разворачивается на весь экран, неявное ожидание 10 секунд.

## Чек-лист

### Страница логина

- [ ] Поля Username и Password отображаются, кнопка Login активна
- [ ] Вход с валидными данными (`standard_user` / `secret_sauce`) — открывается страница товаров, URL `/inventory.html`
- [ ] Пароль в поле Password скрыт точками
- [ ] Вход с пустым логином — ошибка `Epic sadface: Username is required`
- [ ] Вход с логином без пароля — ошибка `Epic sadface: Password is required`
- [ ] Вход с неверным паролем — ошибка `Epic sadface: Username and password do not match any user in this service`
- [ ] Вход несуществующим пользователем — та же ошибка, что и при неверном пароле
- [ ] Заблокированный `locked_out_user` — ошибка `Epic sadface: Sorry, this user has been locked out.`
- [ ] Ошибка закрывается крестиком в блоке ошибки
- [ ] Логин чувствителен к регистру (`Standard_User` не проходит)
- [ ] Пробелы вокруг логина не обрезаются — вход не выполняется
- [ ] Без авторизации прямой переход на `/inventory.html` возвращает на страницу логина с ошибкой

### Страница товаров

- [ ] Заголовок страницы — `Products`
- [ ] Отображаются 6 товаров, у каждого есть картинка, название, описание, цена и кнопка Add to cart
- [ ] Цены отображаются в формате `$29.99`
- [ ] Кнопка Add to cart после нажатия меняется на Remove
- [ ] Счётчик на иконке корзины увеличивается на 1 при добавлении товара
- [ ] Кнопка Remove убирает товар и возвращает надпись Add to cart
- [ ] Счётчик корзины исчезает, когда корзина пуста
- [ ] Клик по названию товара открывает карточку именно этого товара
- [ ] Кнопка Back to products возвращает на список товаров
- [ ] Сортировка Name (A to Z) сортирует по названию по возрастанию
- [ ] Сортировка Name (Z to A) сортирует по названию по убыванию
- [ ] Сортировка Price (low to high) сортирует по цене по возрастанию
- [ ] Сортировка Price (high to low) сортирует по цене по убыванию
- [ ] Выбранная сортировка сохраняется при возврате со страницы товара
- [ ] Товары, добавленные в корзину, остаются добавленными после перехода между страницами

### Шапка и меню

- [ ] Иконка корзины отображается на всех страницах после логина
- [ ] Бургер-меню открывается и содержит пункты All Items, About, Logout, Reset App State
- [ ] All Items возвращает на страницу товаров
- [ ] About ведёт на сайт saucelabs.com
- [ ] Logout возвращает на страницу логина
- [ ] После Logout возврат по кнопке «назад» браузера не открывает страницу товаров
- [ ] Reset App State очищает корзину
- [ ] Reset App State возвращает кнопкам товаров надпись Add to cart
- [ ] Меню закрывается крестиком

### Корзина

- [ ] Заголовок страницы — `Your Cart`
- [ ] В корзине отображаются добавленные товары с названием, описанием, ценой и количеством
- [ ] Количество товара отображается как `1`
- [ ] Кнопка Remove удаляет товар из корзины
- [ ] Кнопка Continue Shopping возвращает на страницу товаров
- [ ] Кнопка Checkout открывает шаг оформления заказа
- [ ] Пустая корзина не даёт оформить заказ
- [ ] Содержимое корзины сохраняется после ухода со страницы и возврата

### Оформление заказа, шаг 1

- [ ] Заголовок страницы — `Checkout: Your Information`
- [ ] Continue с пустыми полями — ошибка `Error: First Name is required`
- [ ] Continue без Last Name — ошибка `Error: Last Name is required`
- [ ] Continue без Postal Code — ошибка `Error: Postal Code is required`
- [ ] Continue с заполненными полями открывает шаг 2
- [ ] Кнопка Cancel возвращает в корзину
- [ ] Поля не принимают только пробелы
- [ ] Поля имеют ограничение на длину вводимого значения

### Оформление заказа, шаг 2

- [ ] Заголовок страницы — `Checkout: Overview`
- [ ] Отображается список заказанных товаров
- [ ] Item total равен сумме цен товаров в корзине
- [ ] Tax рассчитывается от суммы товаров
- [ ] Total равен Item total плюс Tax
- [ ] Отображаются данные об оплате и доставке
- [ ] Кнопка Cancel возвращает на страницу товаров
- [ ] Кнопка Finish завершает заказ

### Завершение заказа

- [ ] Заголовок страницы — `Checkout: Complete!`
- [ ] Отображается сообщение `Thank you for your order!`
- [ ] Корзина после оформления заказа пуста
- [ ] Кнопка Back Home возвращает на страницу товаров

### Особые пользователи

- [ ] `performance_glitch_user` — вход выполняется дольше обычного, но страница товаров открывается
- [ ] `problem_user` — картинки товаров отображаются корректно
- [ ] `problem_user` — сортировка работает
- [ ] `problem_user` — Remove на странице товаров убирает товар из корзины
- [ ] `problem_user` — поле Last Name на шаге оформления принимает ввод
- [ ] `error_user` — все товары добавляются в корзину
- [ ] `error_user` — кнопка Finish завершает заказ
- [ ] `visual_user` — вёрстка страницы товаров не сломана, иконка корзины на своём месте

### Общие проверки

- [ ] Прямой переход на `/checkout-step-two.html` без прохождения шага 1 запрещён
- [ ] Прямой переход на `/checkout-complete.html` без оформления заказа запрещён
- [ ] Приложение открывается в разных браузерах
- [ ] Вёрстка не ломается при уменьшении окна до 1024 px
